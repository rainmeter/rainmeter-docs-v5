The Debug interface in Rainmeter is much more than the usual version number and link to a website. It is a powerful tool for finding and fixing problems with Rainmeter and skins. It consists of four main tabs:

  • Log: Displays a running log of notifications and errors.
  • Skins: Real-time display of important information about active skins.
  • Plugins: Information about built-in and 3rd-party plugins installed in Rainmeter.

Debug is accessed in several ways:

  • Right-Click the Rainmeter icon in the Windows Notification Area on the taskbar and select "Debug".
  • Click the Open log button in the Manage window.
  • Using the !Debug bang as an action in a skin or from the command line as a parameter to Rainmeter.exe.
  • Right-Click any running skin on the desktop and select "Debug skin".

The Log tab

When opened, the list displays the last 20 messages logged by Rainmeter. While left open, the log continues to add new messages to the top of the list.

The log has four columns of information:

  • Type: The category of message:
     
    Error - An error impacting the functionality of Rainmeter or a skin.
    Warning - An warning that some functionality is outside of normal parameters.
    Notice - Normal activity logged to provide information about the success of some action.
    Debug - Messages generated when Rainmeter or a skin is in Debug mode.
     
  • Time: The system time when the message was logged in Hours:Minutes:Seconds.Milliseconds.
  • Source: The source of the log message (if available) in the form of Config\Skin.ini - [Section].
  • Message: The text of the log message. Select a line and hit CTRL-C to copy the message to the Windows clipboard.

The types of messages that are displayed by the log can be controlled with the checkboxes at the bottom of the list. This can be used to filter the display to only certain kinds of new messages.

Click Clear to remove the current contents of the log panel.

Note: Custom log entries can be created using the !Log bang from a skin, or the print() function in the Lua scripting language. This can be very useful for debugging purposes.

Use the "Log file" pull-down to manage saving all logging to a Rainmeter.log file in #APPDATA#\Rainmeter.

  • Start logging: Start saving all logging to Rainmeter.log.
  • Stop logging: Stop saving all logging to Rainmeter.log.
  • Show log file: View the contents of Rainmeter.log in your default text editor.
  • Delete log file: Delete Rainmeter.log.
 

Note that the level of logging detail that is provided is controlled by Logging / Debug mode in the Manage dialog.

The Skins tab

Extremely powerful tool displaying real-time information about currently active skins. The tab displays a list of currently active skin config names in the pull-down on the top left. Selecting one from the list will display important information about the skin in real time, in the panel on the right.

  • Measures: Information about measures in the selected skin.
     
    Name - The name of the measure.
    Number - The current number value of the measure.
    Hovering over the Number column will display the current MinValue and MaxValue values for the measure, expressed as a range of values.
    String - The current string value of the measure.

    The line will reflect the current Disabled or Paused state of the measure using color highlighting, with disabled measures grayed out, and paused measures having a yellow background.

    The measure name, range, number or string values may be separately copied to the Windows clipboard by right clicking the line. Note that while the information displayed in the panel is limited to 512 characters, the entire measure value will be copied.

  • Variables: Information about variables in the selected skin.
     
    Name - The name of the variable.
    Value - The current value of the variable. The value may be copied to the clipboard by right-clicking.
 

Use the Jump to pull-down to quickly move between the Measures, Variables, and Watch sections.

 

Double-click any Measure or Variable row to set a Watch at the bottom of the panel. Set as many these as you like, to have a convenient place to view selected values in real time.

 

Set both Measure or Variable Watches and evaluate formulas using Measures and / or Variables by clicking the Add watch button.

Right click any Watch to edit or delete it.

 

Use the Skin button to display and use the skin context menu for the current skin.

The Display tab

Provides a list of all system Displays (Monitors) and display Devices (GPU Ports). Shows names, DPI scaling factors, scaled and unscaled screen sizes and work area metrics.

The Network tab

Lists all active and inactive network adapter (NIC) names on the system.

  • Interface Index: The numeric index number assigned by Window at system start
  • Description: The name of the adapter
  • Alias: The network alias assigned to the adapter
  • Type: The type of adapter (generally Ethernet or Wireless)
  • Status: The Connected / Up or Disconnected / Down status of the adapter

The Plugins tab

Information about the built-in and 3rd-party plugins installed in Rainmeter.

  • Name: The name of the plugin .dll file.
  • Version: The version number of the plugin .dll file.
  • Author: The author name and other copyright information about the plugin.

Note: The list contains all plugins installed in Rainmeter. It does not reflect whether a particular plugin is actually loaded or running in a skin.
