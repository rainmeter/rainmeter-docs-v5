--- layout: docs permalink: manual/installing-rainmeter/auto-update/ title: 'Auto Updating Rainmeter' ---

Rainmeter checks for new versions and downloads available updates by default. To change this, open Manage > Settings and use Download updates automatically. Turning it off stops scheduled checks and downloads. You can still update manually from rainmeter.net.

How Auto Update Works

  1. With automatic updates enabled, Rainmeter normally checks five minutes after startup and then once a day.
  2. When an update is ready, Rainmeter shows a Windows notification. Click the notification or choose Install new version from the Rainmeter notification area menu to open the installer. If you leave the update pending, the installer opens the next time you start Rainmeter.
  3. In the confirmation dialog, choose View release notes to read about the update, Install to update and restart Rainmeter, or Cancel to skip this version. The installer starts Rainmeter again if no instance is running.

Downloaded updates

Rainmeter checks the installer's SHA-256 checksum before running it. It stores the downloaded installer in the Updates subfolder of the settings folder and records the pending update in Rainmeter.data. Windows may ask for administrator permission after you choose Install when Rainmeter is installed in Program Files.
