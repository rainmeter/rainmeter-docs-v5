--- layout: docs permalink: manual/scale-and-zoom/ title: 'Scale and Zoom' ---

Rainmeter supports both monitor DPI scaling and zooming individual skins. Skins can resize without requiring #Scale# variables in every meter's W, H, X, Y, or FontSize option.

Monitor scaling

Skins follow the monitor's DPI setting. For example, at 125% scaling, skins grow to match the display scale and are rendered at the new size, rather than enlarging a previously rendered skin. There is no need to change the properties of Rainmeter.exe to keep skins small when increasing the monitor's DPI setting.

Zooming skins

Hold down CTRL-ALT and click to select one or more skins. Drag a corner or edge of the selected skin(s) to increase or decrease their size. Rainmeter redraws fonts and images at the new size. See Arranging Skins for more about selecting skins.

Zoom ranges from a minimum of 10% to a maximum of 500%. At very small sizes, the number of available pixels limits how much detail a skin can display.

You can also choose a zoom percentage from the skin context menu under Settings > Zoom. For finer adjustments, edit the skin's Zoom setting in Rainmeter.ini. A manually entered value is also shown in the context menu. The zoom value is saved with the individual skin's settings in Rainmeter.ini.

Zoom bangs

!SetZoomFactor Parameters: Factor, Config

Sets a skin's zoom factor as part of an action.

  • Factor (required): A zoom factor, such as 1.25 for 125%, or Default to reset the skin to the default zoom.
  • Config (optional): The config name of a loaded skin. Defaults to the current skin. Use * to act on all loaded skins.

Examples:
  • [!SetZoomFactor 1.25 "ConfigName"]
  • [!SetZoomFactor 1.25 *]
  • [!SetZoomFactor Default "ConfigName"]
  • [!SetZoomFactor Default *]

If using this bang to control a different skin, consider using the new !Skin: approach rather than specifying config at the end of the older form of the bang.


Example: [!Skin:SetZoomFactor Illustro\Clock 1.5]


When using this bang to control a skin group, consider using the new !Skin: approach rather than specifying group at the end of the older form of the bang.


Example: [!Skin:SetZoomFactor Group="GroupName" 1.25]

!SetZoomFactorGroup Parameters: Factor, Group

Sets the zoom factor for skins in a skin group.

  • Factor (required): The zoom factor, as described above.
  • Group (required): The name of the skin group.

Example: [!SetZoomFactorGroup 1.25 "GroupName"]

Zoom direction and anchors

When zoom is changed with a bang, the skin expands or contracts around its current anchor point. The default anchor is the upper left corner, so the skin grows down and to the right.

Use !SetAnchor to change AnchorX and AnchorY in the skin's section of Rainmeter.ini. Setting AnchorX=50% and AnchorY=50% makes the skin zoom outward from its center.

Default zoom

Set Default zoom in Manage > Settings to change the default zoom for all skins. Individual skins can override this value by setting their own zoom or by dragging their edges.

The Force checkbox makes all skins use the default zoom and prevents individual zoom changes. Use this setting sparingly, since it also prevents skins from using zoom as part of their functionality.

These settings are stored in the [Rainmeter] section of Rainmeter.ini as DefaultZoom and ForceDefaultZoom.
