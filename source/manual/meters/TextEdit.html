Meter=TextEdit captures and displays text input from a user and acts on the result with various actions.

When clicked on with the mouse or given focus with the [!TextEdit:Focus (MeterName)] bang, the meter will accept text input from the user. Actions can take place when the text input is submitted, using the value of the current visible meter text as a [$Input] variable in the Actions.

The input area will accept all Widows text entering conventions, such as CTRL-Z to "undo" before submitting, pasting text from the Windows clipboard, scrolling through the text with arrow keys, and selecting text to copy, cut or delete using the keyboard or mouse.

Single or Multiline Input

The meter can be designed as either a single line input "field", or a multiline input "box".

Multiline: If 1, the field may hold more than one line. Default 0.

SubmitOnEnter: If 1, the enter key submits instead of adding a line. Default 0 when Multiline=1, otherwise 1.

If set to MultiLine, the meter will grow in height as lines are added, or you may set a fixed input box size with H or limit the growing input box with ClipStringH and ClipString=2. The text will scroll if typing continues past the defined height.

The width of the meter will grow as text is entered, or you may set a fixed input field size with W or limit the growing input field with ClipStringW and ClipString=2. The text will scroll if typing continues past the defined width.

Note that if Multiline=1, then you will need to create a way to execute [!TextEdit:Submit (meter)] to submit the input, as Enter, CTRL-Enter and SHIFT-Enter will all create new lines. Either that, or have OnDismissAction replace OnSubmitAction in your design, and just clicking away from the meter will take the actions. The [$Input] variable is created by any of the Action types.


Note:

Note that the StringEdit meter requires AccurateText=1 in the [Rainmeter] section of the skin.

Formating Options

All of the General Meter Options are available on the meter.

The StringEdit meter has most of the standard formatting capabilities that a String meter has.

See the String meter for details on String formatting options.

  • FontFace
  • FontSize
  • FontColor
  • FontWeight
  • StringAlign
  • StringStyle
  • StringEffect
  • FontEffectColor
  • ClipString
  • ClipStringW
  • ClipStringH
  • TrailingSpaces
  • InlineSetting / InlinePattern

In addition:

InitialText

Default / initial text value displayed in the meter.

PlaceholderText

Label shown if the InitialText option is not defined or the current visible meter text is "".

PlaceholderFontColor, PlaceholderFontFace, PlaceholderFontSize, PlaceholderStringStyle

Formatting options that are similar to the String meter options, but only apply to PlaceHolderText.

CaretColor Default: 255,255,255,255

Color of the blinking cursor caret when the field has focus.

SelectionColor Default: 0,60,107,255

Color of the background when text is selected in the input area.

FocusBorderWidth Default: 0

If larger than 0, and FocusBorderColor is defined, a border is drawn around the text area.

FocusBorderColor

If FocusBorderWidth is larger than 0, the color of the border.

MaxWidth Default: 0

If larger than 0, the maximum amount of characters that can be typed / pasted into the field.

StringCase

Sets the case of both the InitialText option and the text as it is being entered to Upper or Lower.

InputCase

If StringCase is not defined, this will set the case of just the text as it is being entered to Upper or Lower.

Password Default: 0

If set to 1, masks the input / pasted text and keeps it off the clipboard.

InputFilter

Restricts what the user can type or paste into the field.

InputFilter=Integer						; e.g. -12
InputFilter=Decimal						; e.g. -1.5
InputFilter=Numeric						; e.g. 123
	
InputFilter=RegExp
InputRegExp=[0-9]{1,3}(\.[0-9]{1,3}){3}		; an IPv4 address

InputFilter=RegExp
InputRegExp=#[0-9A-Fa-f]{6}				; a hex color

InputFilter=RegExp
InputRegExp=[^@]+@[^@]+\.[A-Za-z]{2,}		; an email address
