Meter=TextEdit captures and displays text input from a user and acts on the result with various actions.

When clicked on with the mouse or given focus with the [!TextEdit:Focus (MeterName)] bang, the meter will accept text input from the user. Actions can take place when the text input is submitted, using the value of the current visible meter text as a [$Input] variable in the Actions.

The input area will accept all Widows text entering conventions, such as CTRL-Z to "undo" before submitting, pasting text from the Windows clipboard, scrolling through the text with arrow keys, and selecting text to copy, cut or delete using the keyboard or mouse.

Single or Multiline Input

The meter can be designed as either a single line input "field", or a multiline input "box".

Multiline: If 1, the field may hold more than one line. Default 0.

SubmitOnEnter: If 1, the enter key submits instead of adding a line. Default 0 when Multiline=1, otherwise 1.

If set to MultiLine, the meter will grow in height as lines are added, or you may set a fixed input box size with H or limit the growing input box with ClipStringH and ClipString=2. The text will scroll if typing continues past the defined height.

The width of the meter will grow as text is entered, or you may set a fixed input field size with W or limit the growing input field with ClipStringW and ClipString=2. The text will scroll if typing continues past the defined width.

Note that if Multiline=1, then you will need to create a way to execute [!TextEdit:Submit (meter)] to submit the input, as Enter, CTRL-Enter and SHIFT-Enter will all create new lines. Either that, or have OnDismissAction replace OnSubmitAction in your design, and just clicking away from the meter will take the actions. The [$Input] variable is created by any of the Action types.


Note:

The TextEdit meter requires AccurateText=1 in the [Rainmeter] section of the skin.

Formating Options

All of the General Meter Options are available on the meter.

The TextEdit meter has most of the standard formatting capabilities that a String meter has.

See the String meter for details on String formatting options.

  • FontFace
  • FontSize
  • FontColor
  • FontWeight
  • StringAlign
  • StringStyle
  • StringEffect
  • FontEffectColor
  • ClipString
  • ClipStringW
  • ClipStringH
  • TrailingSpaces
  • InlineSetting / InlinePattern

Meter Options


InitialText

Default / initial text value displayed in the meter.

PlaceholderText

Label shown if the InitialText option is not defined or the current visible meter text is "".

PlaceholderFontColor, PlaceholderFontFace, PlaceholderFontSize, PlaceholderStringStyle

Formatting options that are similar to the String meter options, but only apply to PlaceHolderText.

CaretColor Default: 255,255,255,255

Color of the blinking cursor caret when the field has focus.

SelectionColor Default: 0,60,107,255

Color of the background when text is selected in the input area.

FocusBorderWidth Default: 0

If larger than 0, and FocusBorderColor is defined, a border is drawn around the text area.

FocusBorderColor

If FocusBorderWidth is larger than 0, the color of the border.

MaxWidth Default: 0

If larger than 0, the maximum amount of characters that can be typed / pasted into the field.

StringCase

Sets the case of both the InitialText option and the text as it is being entered to Upper or Lower.

InputCase

If StringCase is not defined, this will set the case of just the text as it is being entered to Upper or Lower.

Password Default: 0

If set to 1, masks the input / pasted text and keeps it off the clipboard.

InputFilter

Restricts what the user can type or paste into the field.

InputFilter=Integer						; e.g. -12
InputFilter=Decimal						; e.g. -1.5
InputFilter=Numeric						; e.g. 123
	
InputFilter=RegExp
InputRegExp=[0-9]{1,3}(\.[0-9]{1,3}){3}		; an IPv4 address

InputFilter=RegExp
InputRegExp=#[0-9A-Fa-f]{6}				; a hex color

InputFilter=RegExp
InputRegExp=[^@]+@[^@]+\.[A-Za-z]{2,}		; an email address

Meter Bangs

  • [!TextEdit:Focus (meter)]
    Gives the named or current meter the focus and begins entry.
    OnFocusAction is executed.
  • [!TextEdit:Submit (meter)]
    Submits the entered string on the named or current meter.
    OnSubmitAction is executed.
  • [!TextEdit:Dismiss (meter)]
    Dismisses the focus from the named or current meter.
    OnDismissAction is executed
  • [!TextEdit:Clear (meter)]
    Sets the visible meter text on the named or current meter to "".
  • [!TextEdit:Reset (meter)]
    Sets the visible meter text on the named or current meter to the value in InitialText.
  • [!TextEdit:SetText (meter) "Some Text"]
    Sets the visible meter text on the named or current meter to a value.
  • [!TextEdit:ScrollByLine (meter) numLines]
    Number of lines to move multiline text by (positive towards the end, negative towards the start.
  • [!TextEdit:ResetScroll (meter)]
    Reset the scroll to the start for both multi-line and single-line meters.
  • [!TextEdit:Select (meter) startposition length] ; -1 as length will select until the end
    Selects and highlights a measured portion of the visible meter text on the named or current meter.
  • [!TextEdit:SelectAll (meter)]
    Selects and highlights the entire visible meter text on the named or current meter.

Meter Actions

When any of the Actions are executed a [$Input] variable is populated with the current visible meter text and is available for use during the Actions.

  • OnFocusAction:
    Executed when the meter is given focus by clicking on it,
    or with the [!TextEdit:Focus MeterName] bang.

  • OnSubmitAction:
    Executed when SubmitOnEnter=1 and Enter is pressed,
    or when submitted with the [!TextEdit:Submit MeterName] bang.

  • OnDismissAction:
    Executed when the meter loses focus by clicking away from it,
    or with the [!TextEdit:Dismiss MeterName] bang.

Examples

Example of a single line input field:

``` ini [Rainmeter] Update=1000 DynamicWindowSize=1 AccurateText=1 [MeterEdit] Meter=TextEdit ; No W or H are set, so the meter will grow to accommodate PlaceholderText or grow / shrink to accommodate the entered or InitalText W=200 FontColor=255,134,87,255 SolidColor=0,0,0,255 FontSize=13 Padding=5,5,5,5 AntiAlias=1 ; PlaceholderText is a way to set a "label" on the field that isn't editable or involved in the value ; It is only used if the visible meter text is "" ; It disappears as soon as you start typing ; It is also a way to set a default / starting W for the meter if the visible meter text is "" PlaceholderText=No Text, Enter Some PlaceholderFontColor=150,150,150,255 PlaceholderStringStyle=Italic ; InitialText is the starting / default value ; If the value is set to "", then PlaceholderText will be shown InitialText=Initial Value of the text ; Just demonstrating that formatting like InlineSetting will be applied to the visible meter text ; before, during and after you edit it. Apply a gradient. ; Note that this is applied once per "update" while entering, so a lower Update value ; can make this effect a bit "smoother" ; Note that InitalText cannot be altered with !SetOption. ; Use [!TextEdit:SetText MeterName "Some Text"] to change the visble meter text InlineSetting=GradientColor | 180 | 255,222,161,255 ; 0.1 | 240,108,95,255 ; 1.0 OnFocusAction=[!SetUpdate 16][!Log "Focus [$Input]"][!TextEdit:SelectAll] OnDismissAction=[!SetUpdate 1000][!Log "Dismiss [$Input]"][!Update] OnSubmitAction=[!SetUpdate 1000][!Log "Entered [$Input]"][!SetOption MeterDisplay Text "Current Value: [$Input]"][!Update] [MeterSet] Meter=String Y=10R FontColor=255,255,255,255 FontSize=12 SolidColor=0,0,0,1 Text=Set Value AntiAlias=1 LeftMouseUpAction=[!TextEdit:SetText MeterEdit "Value Set By Bang"][!SetOption MeterDisplay Text ""][!Update] [MeterClear] Meter=String Y=r X=15R FontColor=255,255,255,255 FontSize=12 SolidColor=0,0,0,1 Text=Clear Value AntiAlias=1 LeftMouseUpAction=[!TextEdit:Clear MeterEdit][!SetOption MeterDisplay Text ""][!Update] [MeterReset] Meter=String Y=r X=15R FontColor=255,255,255,255 FontSize=12 SolidColor=0,0,0,1 Text=Reset Value AntiAlias=1 LeftMouseUpAction=[!TextEdit:Reset MeterEdit][!SetOption MeterDisplay Text ""][!Update] [MeterDisplay] Meter=String Y=15R X=0 FontColor=255,255,255,255 FontSize=12 SolidColor=0,0,0,1 AntiAlias=1 ```
