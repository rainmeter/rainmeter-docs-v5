Meter=SVG is a meter designed to display SVG (Scalable Vector Graphics) images from file or embedded code.

Options

All of the General Meter Options are available on the meter.

SVGImage
The SVG image to display.

This can take one of two formats:
  • A path and name of a valid .svg image file.
  • The full SVG code of an SVG image.

SVG code documentation

Examples:
SVGImage=#@#Images\RedDot.svg
SVGImage=<svg height="100" width="100"><id "dot" circle r="45" cx="50" cy="50" fill="red" /></svg>
Attribute, Attribut2, Attribute3... Format: selector | attribute | value
One or more changes to be applied to elements in the SVG file or embedded code.

Use svg as the selector to target the root element, or * to apply the attribute to every element in the document, or any valid id name from the document (e.g. <id "dot" circle...>).

SVG supported elements and attributes

Examples:
Attribute=svg | opacity | 0.75
Attribute2=* | stroke-width | 5
Attribute3=dot | fill | #fce3c3

Example

``` ini [Rainmeter] Update=1000 DynamicWindowSize=1 AccurateText=1 [MeterCalendarFile] Meter=SVG SVGImage=#@#SVG\calendar.svg W=100 [MeterRainmeterLogoCode] Meter=SVG Y=10R SVGImage= Attribute=water | fill | #fce3c3 Attribute2=svg | opacity | 0.75 W=100 ```
