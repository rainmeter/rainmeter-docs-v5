Meter=SVG is a meter designed to display SVG (Scalable Vector Graphics) images from file or embedded code.

Options

All of the General Meter Options are available on the meter.

SVGImage
The SVG image to display.

This can take one of two formats:
  • A path and name of a valid .svg image file.
  • The full SVG code of an SVG image.
    As with all option values in Rainmeter, the code must be all on one line, with no line breaks.

See SVG support and limitations for the elements and attributes that Rainmeter can render.

Examples:
SVGImage=#@#Images\RedDot.svg
SVGImage=<svg height="100" width="100"><circle id="dot" r="45" cx="50" cy="50" fill="red" /></svg>
Attribute, Attribute2, Attribute3... Format: selector | attribute | value
One or more changes to be applied to elements in the SVG file or embedded code.

Use svg as the selector to target the root element, or * to apply the attribute to every element in the document, or any id name from the document (e.g. <circle id="dot"...>).

See SVG support and limitations for the attributes that Direct2D recognizes.

Examples:
Attribute=svg | opacity | 0.75
Attribute2=* | stroke-width | 5
Attribute3=dot | fill | #fce3c3

SVG support and limitations

Rainmeter uses Windows Direct2D to render SVG files and inline SVG code. Direct2D supports a subset of SVG 1.1 and ignores unsupported elements and attributes. An SVG that displays correctly in a browser may therefore appear incomplete in Rainmeter.

  • Supported features include shapes such as <rect> and <circle>, vector paths, fills, strokes, linear and radial gradients, and clipping paths.
  • Text elements such as <text> and <tspan>, as well as SVG filters and masks, are ignored. Convert fixed lettering to paths in a vector editor or use a String meter for text that changes.
  • Images referenced by <image> must be embedded as base64 data. Direct2D ignores references to external images.

For the full list of supported elements, attributes, and length units, see Microsoft's Direct2D SVG support reference.

Example

``` ini [Rainmeter] Update=1000 DynamicWindowSize=1 AccurateText=1 [MeterCalendarFile] Meter=SVG SVGImage=#@#SVG\calendar.svg W=100 [MeterRainmeterLogoCode] Meter=SVG Y=10R SVGImage= Attribute=water | fill | #fce3c3 Attribute2=svg | opacity | 0.75 W=100 ```
