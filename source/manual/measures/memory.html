--- layout: docs permalink: manual/measures/memory/ title: 'Memory measures' ---
  • Measure=PhysicalMemory reports physical RAM. It uses ullTotalPhys for the total and subtracts ullAvailPhys for used RAM.
  • Measure=SwapMemory uses ullTotalPageFile for the commit limit reported to Rainmeter. Its used value is that limit minus ullAvailPageFile.
  • Measure=Memory adds the physical-memory and commit figures used by the other two measures.

Windows can limit the commit figures for the calling process. These figures describe memory commitment, so use a different source to measure the size or disk usage of a page file. See the Windows memory status fields.

By default the value will be the amount of used memory. To obtain the free memory, add InvertMeasure=1.

The measures will have a MinValue / MaxValue range from 0 to the actual total size of the measured memory resource for use by meters requiring a percentage.

Options

General measure options
All general measure options except MaxValue are valid.
Total Default: 0
If set to 1, measures the total memory.

Example

``` ini [Rainmeter] Update=1000 AccurateText=1 DynamicWindowSize=1 [MeasurePhysMemTotal] Measure=PhysicalMemory Total=1 UpdateDivider=3600 [MeasurePhysMemUsed] Measure=PhysicalMemory UpdateDivider=2 [MeasurePhysMemFree] Measure=PhysicalMemory InvertMeasure=1 UpdateDivider=2 [MeterText] Meter=String MeasureName=MeasurePhysMemTotal MeasureName2=MeasurePhysMemUsed MeasureName3=MeasurePhysMemFree FontColor=255,255,255,255 SolidColor=47,47,47,255 Padding=5,5,5,5 AntiAlias=1 NumOfDecimals=1 AutoScale=1 Text="RAM Total: %1B, RAM Used: %2B, RAM Free: %3B" ```
