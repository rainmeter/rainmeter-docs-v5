--- layout: docs permalink: manual/measures/dragdrop/ title: 'DragDrop measure' ---

Measure=DragDrop will detect and react to files and folders being dragged from outside of Rainmeter and dropped on a Rainmeter skin.

Note:

The DragDrop measure is based on the plugin Drag&Drop by theAzack9.

Options

General measure options

All general measure options are valid.


Note:

The value of the measure will always be the path of the last dropped file or folder.

Parent and child options

These options can be used on both parent and child measures.

Action Default: Path

The action defines what function the measure has, there are currently five options:

  • Move
    Moves the file / folder dropped to the path specified in the Path option.
  • Copy
    Copies the file / folder dropped to the path specified in the Path option.
  • Shortcut
    Creates a shortcut file (.lnk) to the file / folder dropped to the path specified in the Path option.
  • Delete
    This moves the file / folder to the recycle bin.
  • Path
    This is used to get information about the file dropped.

Example: Action=Path

Path

The full path to the folder you want the measure to move / copy to or create shortcut in.


Note: If the target folder does not exist it will be created when a file / folder is moved to it


Example: Path=#@#Shortcuts\

Silent Default: 0

A value of 1 stops the measure from showing any delete confirmation dialogs.

ReplaceIfExists Default: 0

A value of 1 allows the measure to overwrite existing files.

FancyRenderer Default: 1

A value of 0 disables the object preview rendered while dragging a file or folder.


Note: This option is only valid on a parent measure.

ProcessAllFiles Default: 0

A value of 1 tells the measure to repetitively execute the action option on all files when multiple are dragged. Each file can be enumerated with the $FileNr$ substitute. If this is set to 0, $FileNr$ will be 1.

Child options

These options can be used on child measures.

Parent

Defines the parent measure for the current measure.


Example: Parent=MyParentMeasure

Bounds

The target bounds in the skin where it is possible to drop file(s) or folder(s) for the child measure.

This will take one of two forms:

  • A definition of a target area as X,Y,W,H relative to the skin.
    Example: Bounds=0,0,100,200
  • The name of a meter in the skin to use as the target area.
    Example: Bounds=MyMeter

Note: If Bounds is not defined, then the entire skin becomes the target.

Action options

These options can be used on both parent and child measures.

OnDropAction

Action to execute when the file is dropped on the target.

OnEnterAction

Action to execute when the cursor enters the target area while dragging file(s) or folder(s).

OnLeaveAction

Action to execute when the cursor leaves the target area while dragging file(s) or folder(s).

OnOverAction

Action to execute while the cursor is hovering over the target area while dragging file(s) or folder(s).


Note: This action will be called approximately every 20ms while hovering.

Event Variables

The following variables will be created and available for use inside:


OnDropAction, OnEnterAction, OnLeaveAction, OnOverAction


  • $Name$
    Replaced with the file name
  • $Directory$
    Replaced with the folder name
  • $Type$
    Replaced with the file extension. (e.g exe, lnk, txt)
  • $File$
    Replaced with the full file or folder path and name.
  • $FileNr$
    Replaced with the number of the currently processed file.
  • $MouseX$
    X position of the mouse
  • $MouseY$
    Y position of the mouse

Example: OnDropAction=[!Log "You dropped the file $File$ on the target."]

Example

``` ini [Rainmeter] Update=1000 AccurateText=1 DynamicWindowSize=1 SkinWidth=260 SkinHeight=180 BackgroundMode=2 SolidColor=47,47,47,255 [MeasureParent] Measure=DragDrop [MeasureTarget1] Measure=DragDrop Parent=MeasureParent Action=Path Bounds=MeterTarget1 OnDropAction=[!log "You dropped the file: $Directory$\$Name$.$Type$ on MeterTarget1"][!SetOption MeterSkinLabel Text "$Name$.$Type$"][!UpdateMeter *][!Redraw] [MeterTarget1] Meter=Image X=20 Y=20 W=100 H=100 SolidColor=255,255,255,255 [MeasureTargetImage] Measure=DragDrop Parent=MeasureParent Action=Path Bounds=MeterTargetImage OnDropAction=[!Log "Updating image on MeterTargetImage with $File$"][!SetOption MeterSkinLabel Text "$Name$.$Type$"][!UpdateMeter *][!Redraw] [MeterTargetImage] Meter=Image MeasureName=MeasureTargetImage X=20R Y=r W=100 H=100 SolidColor=255,255,255 PreserveAspectRatio=2 [MeterSkinLabel] Meter=String FontSize=13 FontColor=255,255,255,255 X=235 StringAlign=Right Y=140 AntiAlias=1 [MeterTarget1Label] Meter=String FontSize=12 FontColor=47,47,47,255 X=28 Y=40 AntiAlias=1 Text=Target1:#CRLF#Drop File [MeterTargetImageLabel] Meter=String FontSize=12 FontColor=47,47,47,255 X=148 Y=40 AntiAlias=1 Text=Drop Image ```
