JSONPointer is used to parse individual elements of JSON data in a WebParser measure. The retrieval can be in any order, since the exact position of the data in the JSON "tree" is given in the option.

If the site you are accessing compresses the JSON data, removing the linefeeds and tabs that make the code more human readable, you can use this site to "pretty" the data to help with your analysis:

Web Formatter

Options


The JSONPointer option is used with normal WebParser measure(s), and supports all WebParser options except RegExp and StringIndex.

URL
Formatted exactly the same as any WebParser measure.

If URL=[SomeMeasure] then the measure is a "child" to the "parent" [SomeMeasure]. Thus the skin will only need to go out and retrieve the site or file information once per UpdateRate.
JSONPointer
Replaces RegExp and StringIndex options.

Uses JSONPointer functionality to reach directly into the JSON code, picking off individual elements of data based on the JSON "tree" hierarchy.

It uses forward slashes / to separate keys (for objects) or numbers (for zero-based arrays).

Any literal / or ~ inside a JSON key name must be escaped:
~1 represents a literal forward slash ~0 represents a literal tilde ~

If set to 1, the measure will act as a traditional WebParser "parent". Not required, as any measure with a URL to a resource is at once a "parent" and a "child" if JSONPointer is defined as a key/element.

Example:
JSONPointer=/books/1/title
Will return the "title" of the second element of the "books" array.

Basic Navigation Examples

The following example evaluates against this JSON document:

``` txt { "store": "Central Market", "books": [ { "title": "The Hobbit", "author": "Tolkien" }, { "title": "1984", "author": "Orwell" } ] } ```

Using these measures:

``` ini [MeasureJSONParent] Measure=WebParser URL=file://#@#SomeJSON.txt JsonPointer=1 [MeasureStore] Measure=WebParser URL=[MeasureJSONParent] JsonPointer=/store [MeasureFirstAuthor] Measure=WebParser URL=[MeasureJSONParent] JsonPointer=/books/0/author [MeasureSecondTitle] Measure=WebParser URL=[MeasureJSONParent] JsonPointer=/books/1/title ```

With these results:

JSON Pointer Evaluated Value Explanation
/store "Central Market" Accesses the "store" key of the root object.
/books/0/author "Tolkien" Accesses the first element (index 0) of the "books" array, then fetches its "author" key.
/books/1/title "1984" Navigates to the second array element, then fetches its "title" key.
