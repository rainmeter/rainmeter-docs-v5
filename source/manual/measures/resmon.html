Measure=ResMon monitors the use of resources.

Note: ResMon was previously a plugin measure.

Toggle

In many existing skins you might see the syntax:

``` ini [MeasureParent] Measure=Plugin Plugin=ResMon or Plugin=ResMon.dll or Plugin=Plugins\ResMon.dll ```

ResMon still works with those forms, and changing existing skins to the new Measure=ResMon syntax is entirely optional. However, new skins created going forward should use the correct syntax for accuracy and clarity. ResMon is a measure, and not a plugin.

``` ini [MeasureParent] Measure=ResMon ```

Options

General measure options
All general measure options are valid.
ResCountType Default: GDI
Type of resource to measure. Valid values are:
  • GDI: Number of GDI objects.
  • USER: Number of USER objects.
  • Handle: Number of open handles.
  • Window: Number of open system window handles.
ProcessName
If specified, the resource use of the specified process is measured.

Example

``` ini [Rainmeter] Update=1000 DynamicWindowSize=1 BackgroundMode=2 SolidColor=0,0,0,255 [MeasureSystemGDI] Measure=Resmon ResCountType=GDI [MeasureRainmeterGDI] Measure=Resmon ResCountType=GDI ProcessName="Rainmeter.exe" [MeterOne] Meter=String MeasureName=MeasureSystemGDI MeasureName2=MeasureRainmeterGDI FontSize=12 FontColor=255,255,255,255 StringStyle=Bold AntiAlias=1 Text=GDI Handles: %1 (Rainmeter: %2) ```
