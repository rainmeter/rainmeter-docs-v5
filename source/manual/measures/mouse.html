Measure=Mouse detects mouse events and does two things. First, it can execute actions for each kind of mouse event, and second, it will return variables containing the X and Y coordinates of the cursor, relative to either the current monitor or the skin.

Mouse Events

The following mouse actions are triggered by the corresponding mouse events anywhere on the skin:

  • MouseMoveAction
    Triggered when the measure is active and the mouse is moved
  • LeftMouseDownAction
  • LeftMouseUpAction
  • LeftMouseDragAction
    Triggered when the measure is active and the mouse is dragged with the button down
  • RightMouseDownAction
  • RightMouseUpAction
  • RightMouseDragAction
    Triggered when the measure is active and the mouse is dragged with the button down
  • MiddleMouseDownAction
  • MiddleMouseUpAction
  • MiddleMouseDragAction
    Triggered when the measure is active and the mouse is dragged with the button down
  • X1MouseDownAction
  • X1MouseUpAction
  • X1MouseDragAction
    Triggered when the measure is active and the mouse is dragged with the button down
  • X2MouseDownAction
  • X2MouseUpAction
  • X2MouseDragAction
    Triggered when the measure is active and the mouse is dragged with the button down

Note:

Many of these Mouse Actions are the same as those supported on the skin background or a meter.

The actions executed by the Mouse measure will happen in addition to any actions defined on the skin background or a meter. Some care should be taken to anticipate possible conflicts.

MouseMoveAction will be executed before any mouse drag actions.

Mouse Variables

During the Mouse Actions, temporary variables $MouseX$ and $MouseY$ are set with the mouse X and Y coordinates. The variables are only created and used in the context the action. Primarily, they will be used as a parameter to a Bang.

Example: LeftMouseUpAction=[!SetOption SomeMeter X $MouseX$][!UpdateMeter *][!Redraw]

Options

General measure options
All general measure options are valid.
RelativeToSkin Default: 1
If set to 1, the coordinates returned are relative to the skin. If set to 0, the coordinates returned are relative to the current monitor.
RequireDragging Default: 0
If set to 0, the measure is constantly monitoring the mouse position and capturing mouse events. If set to 1 then dragging can be facilitated by turning the measure on and off with the !CommandMeasure bang, commanding Start or Stop:

``` txt LeftMouseDownAction=[!CommandMeasure MeasureName "Start"] LeftMouseDragAction=[!Log "The mouse is at $MouseX$, $MouseY$"] LeftMouseUpAction=[!CommandMeasure MeasureName "Stop"] ```
CaptureOverlayCursorName Default: ARROW

Chooses the system cursor displayed during click capture. The following cursor values from Mouse Cursor Options are supported:

  • ARROW
  • HAND
  • TEXT
  • HELP
  • BUSY
  • CROSS
  • PEN
  • NO
  • SIZE_ALL
  • SIZE_NESW
  • SIZE_NS
  • SIZE_NWSE
  • SIZE_WE
  • UPARROW
  • WAIT

Example: CaptureOverlayCursorName=CROSS

Bangs

The Mouse measure can capture the next click anywhere on any monitor, including outside the skin, using !Mouse:StartCapture and !Mouse:StopCapture. In the examples below, MeasureMouse is the section name of the Mouse measure.

!Mouse:StartCapture Parameter: MeasureName

Starts a capture that waits for the next mouse click anywhere on any monitor. When the button is released, the capture ends and the measure executes the corresponding LeftMouseUpAction, RightMouseUpAction, MiddleMouseUpAction, X1MouseUpAction, or X2MouseUpAction.

The action can use $MouseX$ and $MouseY$ for the coordinates where the button was released, according to RelativeToSkin. The captured click is consumed and does not reach the skin or application underneath.

Any mouse buttons already held when capture starts must be released before the next click can be captured. Only one capture can be active at a time; starting another replaces the current capture. The measure must be enabled and unpaused.

The cursor displayed during capture is set with CaptureOverlayCursorName.

  • MeasureName (optional): The section name of the Mouse measure in the current skin. If omitted, the bang acts on the Mouse measure from which it is executed.

Example: [!Mouse:StartCapture "MeasureMouse"]
!Mouse:StopCapture Parameter: MeasureName

Cancels an active capture for the specified measure without executing a mouse action. Pressing Esc, disabling or pausing the measure, or unloading the skin also cancels capture.

  • MeasureName (optional): The section name of the Mouse measure in the current skin. If omitted, the bang acts on the Mouse measure from which it is executed.

Example: [!Mouse:StopCapture "MeasureMouse"]

Capture Example:

``` ini [MeasureMouse] Measure=Mouse RequireDragging=1 CaptureOverlayCursorName=CROSS LeftMouseUpAction=[!Log "Captured click at $MouseX$, $MouseY$"] [MeterCapture] Meter=String Text=Click to capture the next screen click FontColor=255,255,255,255 AntiAlias=1 LeftMouseUpAction=[!Mouse:StartCapture "MeasureMouse"] ```
