Rainmeter is a free, open-source app for Windows that puts clocks, system information, music controls, and other widgets on your desktop. These widgets are called skins.

This guide shows you how to install Rainmeter, use skins, and customize them. Start with Setting Up, or read on for a quick introduction.

What can I do with Rainmeter?

You can choose the skins you want, arrange them on your desktop, and save the arrangement as a layout. Use skins from different authors together to make a desktop that suits you.

Each skin is a separate window that you can drag into place.

What is a skin?

A skin is a desktop widget. It might show the time, track CPU usage, display a picture, or control a music player. A matching collection of skins is called a suite.

Each skin has its own features and settings. Check the author's instructions to learn how to use it.

Do I need to know how to code?

Manage skins through the Manage window or their right-click menus.

You can install and use skins without writing code. Rainmeter's Manage window lets you load and unload skins, adjust their position and transparency, and save layouts. Right-click a skin for its menu.

Some skins include controls for changing colors, fonts, and other settings. Others require you to edit a text file. Follow the author's instructions for the skin you are using.

If you want to make your own skins, the Creating Skins guide will help you get started. Skins use text configuration files: measures gather information, and meters display it. You can learn these as you go.

What are the limits?

  • Rainmeter adds skins to your desktop. It does not change the appearance of the Windows taskbar, Start menu, File Explorer, or desktop icons.
  • Skins that control another app still need that app to be running. A music skin, for example, controls a separate music player.
  • A desktop shown in a screenshot may also use a separate wallpaper, icons, or other customization tools. Check the creator's links to find everything you need.
