Use these methods to build and test the RegExp option on a WebParser measure. For an introduction to parent and child measures, see the WebParser Tutorial.

Set up the local example

Download IP-example.html and save it in your skin's @Resources folder. The sample uses the documentation address 192.0.2.1 and produces the same values in Rainmeter and RainRegExp. The flag path is sample text for the regular expression to capture.

To start building a regular expression, look at the row containing the first value you want:

``` html Your IP Address:192.0.2.1 ```

Start with RegExp=(?siU)<td.*>Your IP Address.*<td>(.*)</td>. The (.*) captures the IP address from the second table cell. Give the child measure StringIndex=1 to retrieve that capture. Add another capture for each value you want, then save and refresh the skin to test the result.

Check the captures in Rainmeter

In this complete skin example, MeasureSite reads the local file and captures eight values in order. The child measures specify which capture to return. The string meter displays the first capture.

``` ini [Rainmeter] Update=1000 AccurateText=1 [MeasureSite] Measure=WebParser URL=file://#@#IP-example.html RegExp=(?siU)Your IP Address.*(.*).*Country:.* (.*).*Region.*(.*).*City.*(.*).*ISP:.*(.*).*Latitude:.*(.*).*Longitude:.*(.*) [MeasureIP] Measure=WebParser URL=[MeasureSite] StringIndex=1 [MeasureFlag] Measure=WebParser URL=[MeasureSite] StringIndex=2 [MeasureCountry] Measure=WebParser URL=[MeasureSite] StringIndex=3 [MeasureRegion] Measure=WebParser URL=[MeasureSite] StringIndex=4 [MeasureCity] Measure=WebParser URL=[MeasureSite] StringIndex=5 [MeasureISP] Measure=WebParser URL=[MeasureSite] StringIndex=6 [MeasureLatitude] Measure=WebParser URL=[MeasureSite] StringIndex=7 [MeasureLongitude] Measure=WebParser URL=[MeasureSite] StringIndex=8 [MeterIP] Meter=String MeasureName=MeasureIP FontSize=12 FontColor=255,255,255,255 SolidColor=0,0,0,255 AntiAlias=1 ```

Open Debug → Skins and select the loaded skin. The String column shows the eight captures, from 192.0.2.1 through -77.2883224487.

Get the source text from a website

When debugging a website, start with the response WebParser receives. Your browser's “View page source” command shows the response sent to the browser, which may differ.

Debug=2

Set Debug=2 on the parent measure and load or refresh the skin. WebParser writes the response to WebParserDump.txt in the folder containing the skin's INI file. You can leave RegExp empty while you inspect the response. Remove Debug=2 when you finish testing to stop writing the file.

RainRegExp

RainRegExp is an add-on utility you can use with WebParser / Rainmeter to create, test and debug your RegExp regular expression options. The way the tool works is to actually connect to the site you are using in your URL option, download the text exactly as WebParser would see it, (it basically tells the site it IS WebParser) and give you a way to build and test your RegExp while seeing exactly what is being set in the StringIndex values.

Get the tool here: RainRegExp Releases. Simply unzip the files into any folder you desire, and run the RainRegExp.exe executable.

(1): Type or paste in the URL to connect to and press "Connect", or use "Browse" to open a local HTML / text file. For this example, browse to the downloaded IP-example.html.

(2): The HTML or text from the selected source appears in this panel. You can scroll through it or use the "Search" capability to find the text you want to search for.

(3): Create your RegExp statement here. Click on "Parse" to test as you go. Once you are happy that your expression is working correctly, click on "Copy" to copy the entire RegExp to the Windows clipboard, so you can paste it in your skin.

(4): The output of the "Parse" test will be here. It will consist of the StringIndex number that will be assigned in WebParser and the value captured from the selected source.

Hope this helps with creating and debugging those pesky RegExp statements.
