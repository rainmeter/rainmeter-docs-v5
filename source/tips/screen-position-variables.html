--- layout: docs permalink: tips/screen-position-variables/ title: 'Screen Position Variables' ---

Display variables let you size and position skins using the monitor's current dimensions. The work area is the part of the display left after Windows reserves space for the taskbar and other desktop toolbars.

Size a meter to the work area

To make a meter one-third the width of the work area on the display the skin is mostly on, set its width to W=([$DisplayWorkAreaW] / (3 * [$SkinZoomFactor])). Dividing by the skin zoom factor keeps the rendered width at one-third of the work area in logical desktop pixels. Rainmeter applies skin zoom and monitor DPI scaling when it renders the meter.

Position a skin in a layout

This example places the illustro Clock 16 logical pixels inside the bottom-right corner of the primary monitor's work area at 125% zoom. Edit the existing [illustro\Clock] section in Rainmeter.ini while Rainmeter is closed, or edit the section in Layouts\<layout>\Rainmeter.ini and load the layout. The Clock skin must be installed.

``` ini [illustro\Clock] Active=1 Zoom=125 AnchorX=100% AnchorY=100% WindowX=([$Display1X] + [$Display1W] - [$Display1WorkAreaX] - [$Display1WorkAreaW] + 16)R@1 WindowY=([$Display1Y] + [$Display1H] - [$Display1WorkAreaY] - [$Display1WorkAreaH] + 16)B@1 ```

R@1 and B@1 measure inward from the primary monitor's right and bottom edges. Each expression computes how much space is reserved between that edge and the work area, then adds the 16-pixel inset. AnchorX=100% and AnchorY=100% align the skin's right and bottom edges using its zoomed dimensions, so the inset stays the same when the skin's size changes.

Rainmeter evaluates the formulas when it reads the skin settings. Moving the skin with SavePosition enabled can replace the formulas with the saved coordinates. See WindowX and WindowY for the positioning syntax.
