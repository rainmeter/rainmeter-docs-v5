--- layout: docs permalink: snippets/parse-file-path/ title: 'Parse File Path' ---

Breaks down a Windows path written with backslashes. It accepts drive-qualified absolute paths, UNC paths, and relative paths. End a folder path with a backslash to mark its final component as a folder. A drive or UNC share root may be given on its own.

The result contains Vol for the drive or UNC share root, Dir for directories between that root and the final component, Name for the final component, and Ext for the file extension without the dot. Absent components are omitted. Vol, Dir, and folder names end in a backslash.

``` lua function ParseFilePath(path) assert(type(path) == 'string', 'ParseFilePath expects a string.') local volume, rest = path:match('^(%a:\\)(.*)$') if not volume and path:sub(1, 2) == '\\\\' then volume, rest = path:match('^(\\\\[^\\]+\\[^\\]+)\\?(.*)$') assert(volume and path:sub(3, 4) ~= '?\\' and path:sub(3, 4) ~= '.\\', 'ParseFilePath expects a UNC server and share.') volume = volume .. '\\' elseif not volume then assert(not path:match('^[\\/]') and not path:match('^%a:'), 'ParseFilePath expects a drive-qualified absolute, UNC, or relative path.') rest = path end local result = { Vol = volume } if rest == '' then return result end local folders, name = rest:match('^(.*\\)([^\\]+\\?)$') result.Dir = folders name = name or rest local stem, extension = name:match('^(.+)%.([^%.\\]+)$') result.Name = stem or name result.Ext = extension return result end -- { Vol = 'C:\\', Dir = 'Skins\\', Name = 'Clock', Ext = 'ini' } ParseFilePath([[C:\Skins\Clock.ini]]) -- { Vol = '\\\\server\\share\\', Name = 'Skins\\' } ParseFilePath([[\\server\share\Skins\]]) -- { Dir = 'Skins\\', Name = 'Clock', Ext = 'ini' } ParseFilePath([[Skins\Clock.ini]]) ```
